## BUG-001 [重要度: 高] クリア画面の「つぎの時代へ ▶」ボタンがHTMLの文字列のまま表示され、押せない

- 再現手順：Lv1 縄文をクリア → 結果画面を見る
- 期待値：「つぎの時代へ ▶」ボタン（`data-testid=next-era`）が出て、押すと弥生の動画へ進む
- 実際：`<a class="btn big" href="#/video/1/yayoi" data-testid="next-era">つぎの<ruby>…` のような文字列がそのまま表示される。リンクにならない。最後の時代の「レベルN+1へ ▶」（`next-level`）も同じ
- 原因：`nextBtn` はすでにHTMLなのに、`r()`（= `rubyHtml`、HTMLエスケープあり）に通している
- 該当：`js/screens/battle.js:410`（`${r(nextBtn)}`）。ふりがなは `nextBtn` を作るときに文言部分だけ `r()` に通すべき
- 再現テスト：`tests/e2e/flow.test.js`「クリア画面の「つぎの時代へ」がボタンとして押せて…」

## BUG-002 [重要度: 中] 未作成の lvN.js のレベルで、エラー画面になる／タップしても何も起きない（unhandled rejection）

- 再現手順A：`index.html?nosw#/battle/3/jomon`（または `#/video/3/jomon`）を直接開く（lv3.js が未作成の状態）
- 期待値A：ロックされているのでホーム（またはマップ）に戻される
- 実際A：「エラーがおきました🙇」画面になり、console.error が出る
- 原因A：解放チェックより先に `getStageContent()` を await していて、`import()` の失敗が例外になる
- 該当A：`js/screens/battle.js:26`、`js/screens/video.js:13`
- 再現手順B：前のレベルを全クリアして、未作成のレベルのマップで時代を押す（または通信が切れた状態で時代を押す）
- 期待値B：「このステージは じゅんびちゅう だよ🙇」などのモーダルが出る
- 実際B：何も表示されない。`Uncaught (in promise) TypeError: Failed to fetch dynamically imported module` が出る
- 該当B：`js/screens/levelMap.js:62`（`await getStageContent()` に catch が無い。`!content` の分岐には来ない）
- 再現テスト：`tests/e2e/guard.test.js`「ロックされたレベル（2〜6）の動画・バトルに直接URLで…」「未作成のレベルの時代を押すと「じゅんびちゅう」が出る」、`tests/e2e/robust.test.js`「レベルデータの読み込みに失敗したら、タップしたときに何かメッセージが出る」
- 補足：lv2〜6 がそろえば A・B の「未作成」ケースは出なくなるが、B は通信失敗（オフラインで未キャッシュ）でも起きる

- 再現手順：バトルで最後の問題に正解 → 解説画面（「けっかを見る ▶」）で、戻るボタンを押す／アプリを閉じる／リロード

## BUG-004 [重要度: 中] 読み上げの終了イベントが来ないと、動画が1場面目で止まったままになる（iOS Safari）

- 再現手順：iOS Safari（または読み上げエンジンが `onend`/`onerror` を返さない環境）で動画を再生
- 期待値：読み上げが終わらなくても、一定時間で次の場面へ進む
- 実際：`await speak(text)` が永久に resolve されず、自動再生が止まる。iOS Safari では `speechSynthesis.cancel()` 後や、バックグラウンド復帰後に `onend` が来ないことが知られている。Chrome でも長い文で途中停止するバグがある
- 該当：`js/screens/video.js:84`、`js/audio.js` の `speak()`（タイムアウトのフォールバックが無い）
- 再現テスト：`tests/e2e/robust.test.js`「読み上げの終了イベントが来なくても…」（`speechSynthesis.speak` を何もしない関数にして確認。読み上げオフなら同じ条件で進むことも確認済み）

## BUG-008 [重要度: 低] 出しなおしで、直前にまちがえた問題がすぐにもう一度出ることがある

- 再現手順：問題を出しきったとき、未正解の問題が「直前に出した1問だけ」だと、同じ問題が連続で出る（ふくしゅうモードで2問中1問まちがえた場合などに起きやすい）

## BUG-009 [重要度: 低] iOS でバトル中にアプリを裏にすると、戻った瞬間に時間切れになる（コードレビュー）

## BUG-010 [重要度: 低] Service Worker の更新が1回おくれ、古いエンジンと新しいデータが混ざる可能性（コードレビュー）

- 内容：`VERSION` が固定の stale-while-revalidate なので、更新後の最初の起動は古いファイルが使われる。キャッシュに無いファイル（あとから追加された lv2〜6.js など）だけはネットから新しいものが来るため、古い `battle.js` などと新しいデータ形式が混ざる。また lv2〜6.js は install 時に存在しないとキャッシュされず、オンラインで一度開くまではオフラインで遊べない（→ BUG-002B / BUG-005 につながる）
- 該当：`sw.js:2`、`sw.js:31-51`
- 対策案：リリースごとに `VERSION` を上げる、新しい SW が有効になったらリロードを促す、など
- 再現テスト：なし

## BUG-011 [重要度: 低] iOS で電話・バックグラウンド復帰後に効果音が鳴らなくなる（コードレビュー）

- 内容：iOS Safari の AudioContext は中断後 `state === 'interrupted'` になるが、`'suspended'` のときしか `resume()` していない。また `unlockAudio` は最初の1回だけ（`{ once: true }`）
- 該当：`js/audio.js:12`、`js/main.js:69`
- 再現テスト：なし（実機確認推奨）

## BUG-012 [重要度: 低] きょうのミッションに、未作成・ロック中のレベルのステージが入ることがある（コードレビュー）

- 内容：`getMission` は全84ステージから未クリアを順に3つ選ぶので、レベルの終わりごろに次のレベルの時代が入る。そのレベルがまだロック中ならリンク（`#/level/N`）を押してもホームに戻るだけ、データ未作成なら遊べない
- 該当：`js/state.js:182-192`、`js/screens/home.js:20`
- 再現テスト：なし（仕様判断が必要）
